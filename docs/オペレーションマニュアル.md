# 配送管理システム オペレーションマニュアル

最終更新: 2026-07-06

## この文書について

本書は、配送管理システムを日常業務で使用する方向けの操作マニュアルです。開発者向けの技術仕様は `docs/仕様書.md` を参照してください。

本書は2部構成です。

- **第1部**: 配車担当者・管理者向け（PCブラウザで管理画面を操作する方）
- **第2部**: ドライバー向け（スマートフォンで専用URLにアクセスする方）

---

# 第1部: 配車担当者・管理者向けマニュアル

## 1. ログイン

1. ブラウザでシステムのURLにアクセスすると、ログイン画面が表示されます。
2. 「メールアドレス」「パスワード」を入力し、「ログイン」ボタンを押します。
3. 認証に成功すると、自動的に「ダッシュボード」画面に遷移します。
4. メールアドレス・パスワードが誤っている場合は、赤字で「メールアドレスまたはパスワードが正しくありません」と表示されます。

ログイン後は、画面左側のサイドバーから各機能（ダッシュボード／配送計画一覧／新規配送計画作成／マスタ管理／リアルタイム追跡）に移動できます。右上（サイドバー下部）の「ログアウト」でログアウトできます。

## 2. ダッシュボード

その日（または指定日）の配送状況を一目で確認する画面です。画面右上の「表示日付」で日付を切り替えられます（デフォルトは本日）。

### 2.1 KPIカード

- **本日の計画数**: 対象日に登録されている配送計画の件数
- **完了**: ステータスが「完了」の計画数
- **進行中**: 完了以外で、1件以上の停車地が完了しているプランの数
- **未割り当てトラック**: 全トラック数のうち、その日どの計画にも割り当てられていない台数

### 2.2 ドライバー稼働状況

全ドライバーを「進行中」「配達完了」「待機中」の3グループに分けて一覧表示します。

- **進行中**: 実際にルートが動いている（出発済み、または停車地を1件以上完了）ドライバー
- **配達完了**: 割り当てられたルートの全停車地が完了・スキップ済みのドライバー
- **待機中**: まだルートが動いていないドライバー。トラックが既に割り当てられている場合は名前の横に紫の「稼働前」バッジが付きます（＝今日の出動予定はあるが未出発、という意味）

### 2.3 本日の配送計画（カード一覧）

対象日の配送計画がカード形式で並びます。

- カードをクリックすると、その配送計画の詳細画面（STEP1）に移動します
- カードの色: **完了は緑**、**下書きはグレー**、それ以外（確定・進行中）は白
- 日付の右側に給油アイコン（⛽の線画）が表示されている場合、そのプランのいずれかのルートで給油記録があります
- 各ドライバー行に、そのルートの運行状態バッジが付きます（下書き中のプランでは非表示。詳しくは 4.5 節）
  - 稼働前（紫）／運送開始（オレンジ）／進行中（黄）／運送完了（緑）
- 見出し「本日の配送計画」の右にある並び替えドロップダウンで、カードの表示順を変更できます
  - 出発時刻順（デフォルト）／配送状況順／ナンバー下4桁順／ドライバー名前順／停車件数順／要注意順
  - 「要注意順」は、出発予定時刻を過ぎているのに未出発のルートや、指定時刻に間に合わなそうな停車地があるルートを優先して上に表示します

## 3. 配送計画一覧

対象日の全配送計画を、配車表（ガントチャート）形式で横断的に確認する画面です。

1. 上部の日付選択で対象日を切り替えます（「今日」「明日」「明後日」にはラベルが付きます）。
2. 日付の右のドロップダウンで、ルート（トラック）の表示順を切り替えられます。選択肢はダッシュボードと同じ6種類です。
3. 各ルート行をクリックすると、該当の配送計画の詳細画面に移動します。
4. 行の左側には、トラックナンバー下4桁・ドライバー名・プランステータスバッジ・運行状態バッジ・停車地の完了数が表示されます（完了プランと下書きプランではバッジの出方が異なります。4.5節参照）。
5. 右側のタイムライン上に、出発マーカー・各停車地（丸印。緑＝完了、赤＝時刻指定あり）・完了区間（濃い色）が表示されます。

## 4. 配送計画の作成・編集

### 4.1 新規作成

1. サイドバー「新規配送計画作成」をクリックします。
2. 対象日を選択し、「計画を作成」を押します。
3. 作成されると、その計画の詳細画面（STEP1）に自動的に移動します。新規作成時点のステータスは「下書き」です。

### 4.2 STEP1: 配送ルート編集

- **対象日・出発時間**: 配送日と出発予定時刻を設定します。
- **トラック・ドライバー割り当て**: 使用するトラックとドライバーの組を指定します（複数台編成も可能）。同日・同トラック／同ドライバーが既に別プランで使われている場合は警告が出ます。
- **配送先選択**: 配送先一覧から今回配達する先にチェックを入れます。到着希望時刻を入力した配送先は最優先で順序付けされ、未入力の配送先は自動最適化で並び順が決まります。
- **荷量割合**: 各配送先の積載量（%、10%単位）を設定できます。合計が100%を超えるとエラーになります。
- 画面下部のボタン
  - **「ルートを最適化してStep2へ」**: 選択内容を保存し、ルートの自動最適化（順序・所要時間の再計算）を実行してSTEP2に進みます。配送先・トラック・時刻などを変更した場合はこちらを使用します。
  - **「荷量のみ保存してStep2へ」**: 既にルートが作成済みで、ルート自体（停車順・所要時間）は変えずに荷量割合などの軽微な変更だけを保存してSTEP2に進みます。運送開始済みのルートに対して不要な再計算（現在地基準の到着時刻の再計算）を避けたい場合に有効です。

### 4.3 STEP2: 確認・確定

- 配車表（トラック・ドライバー・停車件数・ドライバー用URL）と、時刻設定の一覧（参照専用）が表示されます。
- **ドライバー用URL**: 「URLをコピー」でクリップボードにコピーできます。**下書き状態のプランでは「確定後に発行されます」と表示され、コピーできません**（4.5節参照）。
- 画面下部のボタン
  - **「Step1に戻る」**: STEP1に戻って内容を編集します。
  - **「計画を確定する」**: プランを「確定」状態にします。確定後も画面はそのまま残るので、続けてURLをコピーできます。
  - **「配送計画一覧へ」**: ステータスを変更せず、配送計画一覧画面に戻ります。

### 4.4 編集可能な期間

以下のいずれかに該当する場合、計画は編集できません（画面にグレーの注意文が表示されます）。

- ステータスが「完了」
- 対象日が「今日〜2日後」の範囲外（3日以上先、または過去の日付）

当日分の計画を編集する場合は、黄色い注意文（「本日分の計画を編集しています。配送中のルートに影響する可能性があるため注意してください。」）が表示されます。

運送開始済みのルートを含む計画をSTEP1で再最適化する場合、既に完了・スキップ済みの停車地はそのまま保持され、未配達分のみ現在地（最新の位置情報→直近の配達地点→車庫の順に判定）を起点に再計算されます。トラック・ドライバーの変更はできません。

### 4.5 下書きと確定の違い

「下書き」は保存しただけでまだ確定していない状態、「確定」はドライバーへの配信を前提とした状態です。両者には以下の違いがあります。

| 項目 | 下書き | 確定 |
|---|---|---|
| ドライバー用URL | 発行されない（アクセスすると「この配送計画はまだ確定されていません」と表示され操作不可） | 発行される |
| ダッシュボード/一覧の運行状態バッジ（稼働前など） | 表示されない | 表示される |
| ダッシュボードのカード色 | グレー | 白（進行中〜完了で緑に変化） |

**運送を開始する前に、必ず「計画を確定する」を押してください。** 下書きのままではドライバーが担当ルートを見ることができません。

### 4.6 計画の削除

計画詳細画面の右上「削除」ボタンから削除できます。削除の可否・確認方法は、運送が実際に始まっているかどうかで変わります。

- **未着手の計画**（すべてのルートが「未開始」）: 確認ダイアログ「この配送計画を削除しますか？この操作は取り消せません。」でOKを押すと削除されます。
- **運送開始済みのルートを含む計画**: 誤操作防止のため二段階の確認が必要です。
  1. 計画日（例: 2026-07-06）の入力を求められます。正しく入力しないと削除は中止されます。
  2. 続けて「本当に削除してよいですか？この操作は取り消せません。」の確認が出ます。

削除すると、紐づくルート・停車地・位置情報履歴・給油記録もすべて削除され、元に戻せません。

## 5. マスタ管理

### 5.1 配送先管理

- **新規登録**: 「名称」「住所」（必須）「電話番号」（任意）を入力し「登録」。「住所確認」ボタンで登録前にジオコーディング結果と地図上の位置を確認できます。
- **CSV一括登録**: `name,address,phone` の列を持つCSVファイルをアップロードして一括登録できます。行ごとにジオコーディングされるため、一部の行が失敗しても成功した行は登録されます（結果は成功/失敗件数とエラー内容で表示）。
- **検索**: 名称・住所の部分一致で絞り込めます。
- 編集・削除機能はこの画面にはありません。

### 5.2 ドライバー管理

- 「固定ルート」「専任」「営業」の3タブで一覧を切り替えます。
- 新規登録には「名称」「電話番号」「免許番号」（すべて必須）と種別の指定が必要です。
- 各ドライバーの「休日設定」リンクから、カレンダー形式で平日の個別休日を設定できます。土日・祝日は自動的に休日として扱われるため、それ以外の平日で休みたい日をクリックしてトグルし、「保存」を押してください（自動保存ではありません）。

### 5.3 トラック管理

- 「ナンバー」「型式」「積載量(kg)」「ステータス（使用可能／使用中／整備中）」を登録します。
- 一覧の「編集」リンクで同じ画面内（別画面遷移なし）に既存値が読み込まれ、更新できます。「キャンセル」で編集を中止します。
- 削除機能はありません。使わなくなったトラックは「整備中」などのステータスに変更して運用してください。

### 5.4 システム設定

会社全体で共通の1セットの初期値を設定します。

- 運送のデフォルト出発時間
- 昼休み時間（開始・終了）
- 配送先での標準積み下ろし時間（分）
- デフォルトの荷量割合（%）

これらは新規計画作成時の初期値として使われます（計画ごとに個別に変更可能です）。

## 6. リアルタイム追跡

当日の全ルートをリアルタイムに地図上で確認する画面です。

1. 左側に本日の全ルートが一覧表示されます（トラックナンバー・状態・ドライバー名・完了件数）。15秒ごとに自動更新されます。
2. ルートを選択すると、そのルートの停車地一覧（完了/スキップ/未訪問）が表示され、地図上でもハイライトされます。
3. 地図上のトラックアイコンをクリックしても、対応するルートが選択されます。

# 第2部: ドライバー向けマニュアル

配送計画がSTEP2で「確定」されると発行される専用URLに、スマートフォンのブラウザでアクセスして使用します。**ログインは不要です。URLを知っている人であれば誰でも開けるため、URLの取り扱いには注意してください。**

計画がまだ「下書き」状態の場合、URLにアクセスしても「この配送計画はまだ確定されていません」と表示され、操作はできません。配車担当者に確認してください。

## 1. 画面の見方

画面上部に、トラックナンバー・プランステータス・配送日・ドライバー名・進捗（完了数/全体数）がまとめて表示されます。

## 2. 給油記録

進捗の下に「給油記録」という項目があります。

- 給油した際は、⛽アイコンのボタンを押してください。押した時刻とともに「◯◯:◯◯に給油しました」という記録がリストに追加されます。
- 押し間違えた場合は、記録の右側にある「取消」ボタンでその記録を削除できます。
- 記録は何回でも追加でき、1日に複数回給油した場合もすべて記録されます。

## 3. 運送開始

まだルートを開始していない場合、画面上部に「運送開始」ボタンが表示されます。出発する際に押してください。

※ 押し忘れた場合でも、最初の停車地で「完了」を押すと自動的に運送開始扱いになります。

## 4. 各停車地の操作

停車地ごとに、名称・到着予定時刻（時刻指定がある場合は赤枠で強調表示）・住所・電話番号（あれば発信リンク）・地図アプリへのリンク（MAP）が表示されます。

- **完了**: 配達が終わったら押します。
- **スキップ**: その配送先を飛ばす場合に押します。
- **取消**: 「完了」または「スキップ」を押した後に表示され、誤操作時は元の「未訪問」状態に戻せます。

## 5. 位置情報の共有

画面下部の「位置情報の共有を開始」を押すと、スマートフォンの位置情報が定期的にシステムに送信され、配車担当者がリアルタイム追跡画面で現在地を確認できるようになります。「位置情報の共有を停止」でいつでも止められます。

## 6. 内容が更新された場合

配車担当者が停車地の構成や時刻を変更すると、画面上部に赤い帯で「ルートが更新されました！内容をご確認ください」という通知が表示されます。「確認」を押すと消えます。

## 7. 配送計画が削除された場合

配車担当者が計画を削除すると、画面が「この配送ルートは削除されました」という表示に切り替わり、それ以降の操作はできなくなります。表示された場合は配送を中止し、担当者に確認してください（位置情報の共有も自動的に停止されます）。

# 付録: ステータス用語集

## 配送計画のステータス

| 表示 | 意味 |
|---|---|
| 下書き | 保存済みだが未確定。ドライバーURLは発行されない |
| 確定 | ドライバーへの配信準備が整った状態 |
| 進行中 | いずれかのルートが稼働を開始している |
| 完了 | 全ルートの配達が完了している |

## ルートの運行状態（ダッシュボード・配送計画一覧のバッジ）

| 表示 | 意味 |
|---|---|
| 稼働前 | まだ出発していない |
| 運送開始 | 出発したが、まだどの停車地も完了していない |
| 進行中 | 1件以上の停車地を完了し、稼働中 |
| 運送完了 | 全停車地が完了・スキップ済み |

## 停車地のステータス

| 表示 | 意味 |
|---|---|
| 未訪問 | まだ完了・スキップの操作がされていない |
| 完了 | 配達完了 |
| スキップ | 配達を飛ばした |
